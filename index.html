ตั้งค่าการเชื่อมต่อฐานข้อมูล

เชื่อมต่อแอปกับ Google Sheets ผ่าน Google Apps Script Web App

  1. เปิด Google Sheet ที่ใช้เก็บข้อมูล → เมนู ส่วนขยาย (Extensions) → Apps Script แล้ววางโค้ดจากไฟล์ apps-script/Code.gs
  2. เลือกฟังก์ชัน setup แล้วกด Run หนึ่งครั้งเพื่ออนุญาตสิทธิ์
  3. กด Deploy → New deployment → Web app ตั้งค่า Execute as: Me และ Who has access: Anyone
  4. คัดลอก Web app URL (ลงท้ายด้วย /exec) มาวางด้านล่าง

ผู้ดูแลระบบสามารถใส่ URL ไว้ในไฟล์ config.js เพื่อให้ทุกเครื่องใช้งานได้ทันทีโดยไม่ต้องตั้งค่า
